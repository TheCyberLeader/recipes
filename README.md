## 💡 How to Use This Repository

1. **Browse by Category**: Click through the folders above to find recipes by main ingredient
2. **Search by Tag**: Use the tags above to find recipes by cuisine, cooking method, or dietary preference  
3. **Recipe Format**: Each recipe includes:
   - Servings
   - Ingredient list with measurements
   - Step-by-step instructions
   - Notes & tips where applicable
   - Tags for easy searching

## 📝 Recipe Template

All recipes follow this format for consistency:
```markdown
# Recipe Name

**Serves:** X | **Prep Time:** X min | **Cook Time:** X min

## Description
Brief description

## Ingredients
- Listed ingredients with measurements

## Instructions
1. Step-by-step
2. Instructions

## Notes
- Tips and variations
- Storage instructions

## Tags
`#category` `#cuisine` `#cooking-method` `#dietary`
```
