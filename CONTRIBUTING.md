# Recipe Template & Guidelines

Personal reference for adding new recipes to maintain consistency across the collection.

## 📝 Recipe Template

All recipes should follow this format:

```markdown
# Recipe Name

**Serves:** X | **Prep Time:** X min | **Cook Time:** X min

## Description
Brief description of the dish - what makes it special, flavor profile, or why you love it.

## Ingredients

- Listed ingredients with measurements
- Keep measurements consistent (cups, tablespoons, etc.)
- Group ingredients by component if recipe has multiple parts

## Instructions

1. Number each step clearly
2. One action per step when possible
3. Include temperatures and times
4. Note visual cues (golden brown, bubbling, etc.)

## Notes

- Tips and variations
- Storage instructions
- Make-ahead options
- Substitution suggestions
- Common mistakes to avoid

## Tags
`#category` `#cuisine` `#cooking-method` `#dietary`
```

## Guidelines

### File Naming
- Use lowercase with hyphens: `chicken-shawarma-salad.md`
- Keep names descriptive but concise
- Place in the appropriate folder (chicken/, beef/, seafood/, etc.)

### Measurements
- Use standard US measurements (cups, tablespoons, teaspoons)
- Include weight in parentheses for precision where helpful: `1 cup (200g) flour`
- Spell out numbers under 10, use numerals for 10+

### Tags
Include relevant tags from these categories:
- **Category**: `#chicken` `#beef` `#seafood` `#vegetarian` `#sides` `#breakfast` `#dessert`
- **Cuisine**: `#lebanese` `#asian` `#mediterranean` `#mexican` `#italian` `#american`
- **Method**: `#grilled` `#baked` `#one-pot` `#slow-cooker` `#instant-pot`
- **Features**: `#quick` `#meal-prep` `#high-protein` `#keto` `#gluten-free`

### Writing Style
- Be clear and concise
- Write in active voice
- Include helpful tips from your experience
- Mention what makes this recipe special to you

### Photos (Optional)
- Add photos to the `/images` folder
- Name them to match the recipe: `chicken-shawarma-salad.jpg`
- Link in the recipe using: `![Recipe Name](../images/recipe-name.jpg)`

## Adding a New Recipe

1. Create the recipe file in the appropriate folder using the template above
2. Follow the formatting guidelines for consistency
3. Update the main README.md to include the recipe in the table of contents
4. Add it to relevant tag categories in the README
